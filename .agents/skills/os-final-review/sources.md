# 教材来源与口径

## 主来源

汤小丹、王红玲、姜华、汤子瀛编著：《计算机操作系统（慕课版）》，人民邮电出版社，2021 年 6 月第 1 版。来源是本项目用户提供的本地 PDF 附件（410 个 PDF 页），未转载整书，也没有使用其他版本的习题编号。版权页在 PDF 第 3 页，印刷目录在 PDF 第 12–18 页，正文 12 章为 PDF 第 22–407 页，参考文献从 PDF 第 408 页起。

正文定位采用 `PDF 页序 = 书页 + 21`，这里的 PDF 页序从封面数为 1，不是阅读器可能显示的印刷页标签。章节标题和起始页据 PDF 书签核对；书签的“图书元数据”和“参考文献”不算作正文。技术型抽取使用现有文本层，整理时校对关键表格、公式和易歧义习题的原版页面；本库不是逐图转录，也不包含抽取全文。

## 复习范围的依据

你的补充考纲是：“只有大题考纲，简答题操作系统的特征、处理机调度、进程同步、I/O，计算题进程调度、银行家算法、生产者消费者、缺页率、磁盘访问时间EAT（注意课后题，有概率从中出题）”。因此本库将这些内容设为主线，其他章节为备查；不推断其他题型范围，也不承诺某题一定会考。

“磁盘访问时间 EAT”存在两种常见所指，已同时覆盖磁盘单次访问与请求分页 EAT，并在题目前说明。全部关键算法答案已独立复算；导航链接和生成文档已检查。[来源页码映射](source-map.json)可用于精确检索，原始全文和临时页面不打包入复习资料。

## 重要口径

| 位置 | 用本库复习时的约定 |
|---|---|
| §1.3，书 p.15–18 / PDF 36–39 | 四个基本特征；并发、共享互为成立条件。 |
| 习题 3 第 20 题，书 p.106–107 / PDF 127–128 | 题意为优先级 1 最高；同优先级和同服务时间，若题目未另定，按给定到达顺序。 |
| §4.1.2，书 p.112–113 / PDF 133–134 | 教材列四条临界区准则，其中“让权等待”原则上应遵循但并非必须。 |

| 习题 6 第 17、21 题，书 p.197–198 / PDF 218–219 | 矩阵题的精确列访结果按页对齐与 FIFO/LRU 的常用假定；第 21 题按缺页返回后重执行，短序列中假定可同时缓存两个有效快表项。 |
| §7.8.3 与习题 7 第 17–18 题，书 p.242–243、246 / PDF 263–264、267 | 教材图 7-33 到当前方向最外的**请求**后折返；若考试明确要求到磁道端点才能折返，则把端点移动计入。习题 7 第 17 题叙述 11 个进程，但只列出 10 个请求，以实际给出的序列为准。 |
