# 计算题 1：进程调度

**教材定位：** §3.1–3.2（书 p.74–84 / PDF 95–105）；习题 3 第 19–21 题（书 p.106–107 / PDF 127–128）。先做第 19、20 题，再看下方过程。

## 考场步骤

1. 写清 `A` 到达、`B` 服务、优先级方向、时间片和抢占条件。若同一时刻有到达和用片完毕两个事件，按题设确定入队先后；未说明时写出你采用的约定。
2. 从最早事件推进时间。CPU 空闲时只选“已到达、未结束且不阻塞”的进程；若队列空，标空闲并跳到下一次到达。非抢占算法在当前任务完成或阻塞前不因新到达改派；抢占算法在有关事件上重判。
3. 时间线上的最后一个运行段终点是该进程完成时间 `F`。算 `T=F−A`、`W=T/B`，分别对 `T` 和 `W` 求平均（不是 `平均 T ÷ 平均 B`）。若题目考等待，只有无 I/O 且无额外阻塞的模型下才直接用 `T−B`；若问首次获得 CPU 的响应时间，用 `首次开始−A`，不要与教材分时系统的端到端响应时间定义混淆。
4. 检查：运行段长度对每个进程求和等于 `B`；无空闲和切换开销时末任务的完成时间等于总服务时间（若从 0 开始）。

| 算法 | 下一次选择的依据 | 最常见误判 |
|---|---|---|
| FCFS | 就绪队列的入队先后 | 等待 I/O 后再次进入就绪队列要按题设重新排队 |
| 非抢占 SJF | 当前就绪者的服务时间最短 | 挑选尚未到达者，或到达即打断 |
| SRTF | 当前就绪者与运行者中，剩余时间最短 | 把原始服务时间当剩余时间 |
| 优先级 | 按题设优先级方向，再处理同级 | 把优先级的数字当成通用高低；不同题方向不同 |
| RR | 运行 `min(时间片, 剩余时间)`，未完成回队尾 | 把 RR 当作按编号顺序循环，不处理新到达或任务完成 |

## 习题 3 第 19 题｜非抢占短进程优先

书 p.106 / PDF 127。按 P1–P5：到达时间 `(0, 0.4, 1.0, 5.5, 7)`，服务时间 `(9, 4, 1, 4, 2)`。同服务时间先到先选。

| 时间段 | 选中 | 决策依据 |
|---|---|---|
| 0–9 | P1 | 0 时刻只有它就绪 |
| 9–10 | P3 | 此时其余都已到达，P3 最短 |
| 10–12 | P5 | 剩下 P2、P4、P5，P5 最短 |
| 12–16 | P2 | P2 和 P4 都需 4，先到先做 |
| 16–20 | P4 | 最后一项 |

按 P1–P5：`F=(9,16,10,20,12)`，`T=(9,15.6,9,14.5,5)`，**平均周转时间 10.62**。即使同长度时 P4 先，这道题的平均周转也不变；分别写出的完成时刻会变。

## 习题 3 第 20 题｜同一数据跑四种算法

书 p.106–107 / PDF 127–128。作业 1–5 都在 0 到达，先后顺序为编号顺序。服务时间 `(10,1,2,1,5)`；优先级 `(3,1,3,4,2)`，题目规定 **1 最高**。同优先级/同服务时按题目给的到达顺序。RR 时间片为 1。

| 算法 | 运行顺序 | 完成时刻（按作业编号） | 平均周转 | 平均带权周转 |
|---|---|---|---:|---:|
| FCFS | 1→2→3→4→5 | (10,11,13,14,19) | 13.4 | 7.26 |
| RR | 1,2,3,4,5,1,3,5,1,5,1,5,1,5,1,1,1,1,1 | (19,2,7,4,14) | 9.2 | 2.84 |
| SJF | 2→4→3→5→1 | (19,1,4,2,9) | 7.0 | 1.74 |
| 非抢占优先级 | 2→5→1→3→4 | (16,1,18,19,6) | 12.0 | 6.36 |

例如 RR 最终 `(19/10+2/1+7/2+4/1+14/5)/5=2.84`。每个编号在 RR 行中代表一片，不代表“该作业全部跑完”。

## 相邻题与抢占变式

- **习题 3 第 21 题**（书 p.107 / PDF 128）：类间优先级按图是 **4 最高**；没有新到达或阻塞时，先在 P1、P2、P3 间 RR，直到该级无就绪者，再轮转 P4、P5，最后轮转 P6、P7、P8。未给服务量和时间片，不能写唯一的完整完工时间表。
- **习题 1 第 26 题**（书 p.38 / PDF 59）：P1 的任务依次为 CPU 60、I/O 80、CPU 20；P2 于 5 ms 到，依次为 CPU 120、I/O 40、CPU 40。可排 CPU：P1 `[0,60)` → P2 `[60,180)` → P1 `[180,200)` → 空闲 `[200,220)` → P2 `[220,260)`；I/O 分别 `[60,140)`、`[180,220)`。两个初段 CPU 共需 180 ms，最后完成初段者至少还需 80 ms，所以 **260 ms 为最短**。
- **自拟抢占检查：** P1 `(A=0,B=7)`、P2 `(2,4)`、P3 `(3,1)`。SRTF：P1 `[0,2)`、P2 `[2,3)`、P3 `[3,4)`、P2 `[4,7)`、P1 `[7,12)`。P2 在 2 到达时应和 P1 剩余的 **5** 比，不和原始 7 比。平均周转 `(12+5+1)/3=6`。
