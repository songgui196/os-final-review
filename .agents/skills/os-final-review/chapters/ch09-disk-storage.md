# 第 9 章 磁盘存储器管理

**位置：** 书 p.280–311 / PDF 301–332。**层级：** 全书备查。大题“磁盘访问时间”的主公式在第 7 章，不能按章名误找。

## 核心框架

本章问的是：**文件块放哪里、空闲块怎么记、I/O 如何提效、故障后如何恢复一致性**。访问一个块的机械时间和磁头请求调度则主要见[第 7 章](ch07-io.md)。文件块布局会影响连续性与 I/O 次数，因而间接影响访问性能。

## 分配方式的取舍（§9.1）

| 外存组织 | 定位方法与优势 | 局限 |
|---|---|---|
| 连续 | 起始块+长度；随机定位和顺序传输直接 | 文件增长困难，空闲空间可能有外部碎片 |
| 链接 | 各块记录下一块，或由 FAT 集中记录后继 | 增长灵活；链式访问随机定位代价高，指针损坏会断链 |
| 索引 | 索引块记录数据块号，多级索引扩展容量 | 随机定位好；索引占空间，小文件需权衡；多级要额外读索引 |

**计算套路：** 块 B 字节、块指针 a 字节，则一索引块有 `k=⌊B/a⌋` 项，一级最多定位 `kB` 数据字节，二级最多 `k²B`；有 d 个直接指针加一个一级索引时容量 `(d+k)B`。索引块本身是否占用题目给定空间要另算，最后一块的内部碎片也要区分。

## 空闲管理、提速、可靠性（§9.2–9.5）

- **空闲表/链表：** 空闲区表适合记录连续区间并合并；空闲链表按块或区连接。搜索和合并的代价取决于组织。
- **位示图：** 每块一位，`n` 块需要 `⌈n/8⌉` 字节；位号从 0 还是 1、0/1 谁代表空闲以题设为准。**成组链接**把若干空闲块号成组存储，减少大链逐项追踪。
- **磁盘缓存与预读、合并写：** 利用重复访问和邻接，减少实际 I/O；写回策略需权衡性能与断电丢失风险。
- **RAID：** 条带化用于并行和带宽，镜像/校验用于冗余。RAID 0 无冗余；RAID 1 镜像；本书还介绍多种校验组织。冗余不等于备份，误删除或逻辑破坏可能同步传播。
- **容错与后备：** 块/控制器等不同层容错、集群与后备系统针对不同故障。DAS、NAS、SAN 区分连接和服务方式；分布式/云存储及 SSD 等为教材的技术背景，不作为当前设备规格。

## 一致性：事务—检查点—并发（§9.6）

事务强调原子、一致、隔离、持久。日志和恢复规则应让失败前后的可见状态符合承诺；检查点记录恢复起点、缩短回放范围，但不是凭空消除日志。并发控制防止交错更新破坏一致性；复制数据还要解决多副本的可见状态与更新协议。

## 演练（自拟，按教材方法）

块 1KB，指针 4B，10 个直接指针与一个一级索引：`k=1024/4=256`，可定位数据容量 `(10+256)×1KB=266KB`。读第 11 个逻辑数据块（从第 1 个开始数）需经一级索引定位；索引块不在缓存时额外读一次，不能把数据读取次数固定为 1。若问磁盘空间占用，索引块的 1KB 也要加。

## 自测与关联

按连续/链接/索引比较顺序和随机访问；独立算位图空间、索引容量；区分冗余、备份和事务恢复。回到[第 8 章](ch08-files.md)确认文件语义，到[I/O 专题](../exercises/05-disk-and-eat.md)计算真正访问时间。
