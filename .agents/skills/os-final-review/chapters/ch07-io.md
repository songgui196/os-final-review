# 第 7 章 输入/输出系统

**位置：** 书 p.199–247 / PDF 220–268。**大题落点：** I/O 简答，磁盘访问时间及 EAT 中的换页成本。

## 先分清“哪层软件”和“谁搬数据”

I/O 系统隐藏设备细节，提供设备无关性，提高处理机/设备利用率，控制设备，实现正确共享并处理错误。分层组织用统一接口把硬件差异留在下层，避免每个应用自己处理不同设备。

| 四层软件（§7.1） | 职责 |
|---|---|
| 用户层 | I/O 库、格式转换、面向用户的假脱机服务 |
| 与设备无关的 I/O 软件 | 统一命名与接口、保护、设备分配、通用缓冲、错误处理 |
| 设备驱动程序 | 将请求变成设备命令、参数，设置寄存器，启动/监控设备 |
| 中断处理程序 | 收到中断后取得完成/错误状态，执行必要处理，报告与唤醒 |

习题 7 第 2 题：写设备寄存器→驱动；权限检查、缓冲管理→设备无关层；整数转打印 ASCII→用户层。硬件不算软件第五层。用户请求向下传播，完成与错误向上返回。

## 硬件、控制方式、中断与驱动（§7.2–7.4）

- **设备控制器**连接 CPU 与设备，可分 CPU 接口、设备接口与控制逻辑，利用控制、状态、数据寄存器接受命令、报告状态与交换数据。字符/块设备的区别是传输和访问组织，不仅是“速度快慢”。
- **独立编址 I/O**用专用指令和独立端口空间；**内存映像 I/O**把控制器寄存器编入地址空间，用相应访存指令操作。这是寻址方式，不是把设备数据永远存进普通内存。
- **轮询**由 CPU 反复查看状态并传送；**中断驱动**设备就绪时通知 CPU，CPU 搬运；**DMA**成块搬运数据，CPU 初始化并处理结束/异常；**通道**执行通道程序，能组织多项 I/O，进一步减少 CPU 控制负担。
- **中断过程**可按识别请求/源、保护现场、执行服务、报告或唤醒、恢复现场/返回作答。实际硬件和 OS 可分担不同步骤；被唤醒者先就绪，不保证立刻运行。驱动完成合法性和状态检查、参数设置、启动等设备相关动作。

## 设备无关性、分配与 SPOOLing（§7.5–7.6）

逻辑设备名映射为物理设备，驱动变化不应迫使所有应用重写。设备分配可能同时需要**设备、控制器、通道**等资源，多资源申请和保持也会带来死锁风险；按系统策略分配/回收并处理等待队列。不要把“正在等设备”当成已永久死锁。

**SPOOLing（假脱机）**用磁盘输入井/输出井、内存缓冲、输入/输出进程和井管理组织数据，提供独占设备的逻辑共享。例如进程把打印任务先交输出井，后台再逐个打印，提高提交灵活性。它没有让一台打印机同刻打印两份任务，也没有消除物理打印时间。

## 缓冲与缓存（§7.7）

**缓冲**缓和速率差、协调数据粒度与时间错配；**缓存**利用重访，减少后端取数据。同一机制可能同时有多种作用，题目按主要目标解释。单缓冲、双缓冲、环形缓冲、缓冲池分别适应简单交接、重叠、连续流和多生产消费对象。

输入 `T`，复制到工作区 `M`，计算 `C`：单缓冲稳态 `max(T,C)+M`；双缓冲稳态 `max(T,C+M)`。有限 `n` 块总时间还含启动和排空，只有一块时仍需 `T+M+C`。习题 7 第 13 题不能把两倍周期直接当答案。

## 磁盘性能与调度（§7.8）

一次机械磁盘访问包含**寻道、旋转延迟、传输**，题给控制器时延再加上。若 `r` 为每秒转数，平均旋转等待 `1/(2r)`；传输 `字节数/每秒字节数`。队列等待是否另计由题设决定。FCFS 按请求先后，SSTF 每次选最近请求，SCAN 按方向扫描后反转，CSCAN 单向服务再回到另一侧；NStepSCAN/FSCAN 用分批或双队列减轻新请求黏住磁头的问题。

**本书图例口径：** SCAN 到最远请求折返；考试若指定端点，则要计端点移动。SSTF 每步最近并不保证全序列最优，也可能让远请求久等。

## 演练与检查
