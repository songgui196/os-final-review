# 第 6 章 虚拟存储器

**位置：** 书 p.172–198 / PDF 193–219。**大题落点：** 缺页率、EAT、页面置换。

## 核心原理：逻辑空间不必全部驻留

常规管理强调程序整体装入并驻留；请求分页利用局部性，只将所需页装入，缺页时再调入。**时间局部性**是近期使用的内容易再用，**空间局部性**是邻近地址容易被访问。虚拟存储器有多次性、对换性、虚拟性，容量仍受地址空间、外存与实现限制，不是无限内存。

## 缺页处理的完整路径（§6.2）

1. 先检查地址与访问权限。若 TLB 命中且有效，形成物理地址访问；未命中就查主存页表。
2. 页表**存在位**为 0：访问的是合法但不驻留的页，产生缺页异常。保存执行信息，确定外存位置。
3. 有空闲页框则直接使用；没有则按置换策略选受害页。若修改位为 1，需要写回，未修改页可以省去写回。
4. 调入所需页，更新页表/置换状态并让淘汰页的旧 TLB 映射失效；按实现更新新 TLB 项。
5. 恢复原指令执行。重执行是否再花 TLB/页表/数据访问时间，按题设费用边界计入。

页表项通常包含页框号、存在位、访问字段、修改位与外存位置。存在位与修改位并不互相替代。一个复杂指令可能访问多个页，所以“一条指令一次缺页”不是普遍结论；缺页也不代表应用访问越界。

## 分配、置换与局部性（§6.2–6.4）

| 选择 | 含义 | 取舍 |
|---|---|---|
| 固定分配、局部置换 | 给定页框数；只淘汰本进程页 | 进程间影响较可控，但分配量不适应阶段变化 |
| 可变分配、全局置换 | 页框数可调整；可从全局候选选受害页 | 资源灵活，但别的进程会影响本进程缺页 |
| 可变分配、局部置换 | 数量可调整；每次淘汰限定自身 | 需配合缺页情况决定增减帧 |
| OPT / FIFO / LRU / LFU | 按未来最晚使用/最早装入/最久未用/较少使用选页 | OPT 用于基准；FIFO 不用访问历史；LRU 用时间次序；LFU 的历史频次可能掩盖阶段改变 |
| Clock / 改进型 Clock | 环形扫描访问位；再考虑修改位减少写回 | 比精确 LRU 容易实现；扫描、复位、指针规则要具体 |
| 页面缓冲 | 保留空闲/修改页列表，批量写回和复用页 | 减少不必要磁盘 I/O，但列表与映射要保持一致 |

**工作集 `W(t,Δ)`**是时间窗口内最近访问的不同页集合，不是访问次数总和。驻留页框不足以覆盖活跃局部性，可能反复换入换出形成**抖动**，CPU 利用率下降。应检查缺页率和工作集，必要时增加有效页框、减少多道程序度或挂起部分进程；继续接纳任务可能更差。

## 演练：相同已装页，不同替换依据

习题 6 第 18 题（书 p.198 / PDF 219）初始装 1、2、3，访问 `1,2,4,2,6,2,1,5,6,1`。第三次换入 4 时，3 最合适被换出。第五次访问 6，OPT 见未来不再需要 4，换出 4；LRU 见过去最久未使用的是 1，换出 1。最终 OPT 3 次缺页、LRU 5 次缺页，缺页率分别 **30%、50%**。[逐次页框表](../exercises/04-page-fault-rate.md)包含全部过程。

## EAT：计入一次缺页的巨大代价

`EAT=Σ(分支概率×分支总时间)`。必须区分**总体缺页率**与**快表未命中条件下的缺页率**，区分“缺页处理时间”是否已含页表更新、重执行和最终数据读取。题目未给 TLB 时间并不代表可以凭空补一个固定常数。

习题 6 第 15 题命中 80%，其余 20% 中 10% 缺页，故总体缺页只有 2%，仍可能把平均时间从微秒推高到数百微秒。详见[第 14、15、21 题 EAT 解析](../exercises/05-disk-and-eat.md)。第 17 题用行/列遍历的缺页数显示局部性；第 19–20 题可用装入/访问时间验证替换规则。
