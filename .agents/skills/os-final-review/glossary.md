# 术语索引

缩写按字母、中文按拼音大致排序；括号为章号。更完整的机制见各章，计算方法见[题库](exercises/README.md)。

- **ACL** — 按对象列访问权限的控制表（8、12）。
- **Clock** — 扫描访问位近似使用历史的置换法（6）。
- **DMA** — 控制器在设备与内存间直接成块传输（7）。
- **EAT** — 不同访存路径概率加权的有效访问时间（5、6）。
- **EDF / LLF** — 最早截止/最低松弛度优先（3）。
- **FCB / inode** — 文件控制块/索引节点（8）。
- **FCFS** — 按到达或入队先后服务（3、7）。
- **FIFO** — 页置换时淘汰最早装入者（6）。
- **IaaS / PaaS / SaaS** — 基础设施/平台/软件服务（11）。
- **JCB** — 保存作业管理信息的作业控制块（3）。
- **KST / ULT** — 内核支持/用户级线程（2）。
- **LRU / LFU** — 最久未用/最少使用置换（6）。
- **NUMA / UMA** — 非统一/统一内存访问结构（10）。
- **OPT** — 未来最晚再用者先淘汰（6）。
- **PCB** — 内核记录与管理进程的控制块（2）。
- **P / V** — 原子申请/归还信号量许可（4）。
- **RAID** — 条带、镜像、校验等磁盘阵列组织（9）。
- **RCU** — 读—复制—更新；旧对象延后回收（10）。
- **RR** — 按时间片轮转（3）。
- **SJF / SRTF** — 最短作业/最短剩余时间优先（3）。
- **SPOOLing** — 磁盘排队实现假脱机（7）。
- **SSTF / SCAN / CSCAN** — 最近寻道/扫描/循环扫描（7）。
- **TCB** — 可信计算基；须信任的保护组件集合（12）。
- **TLB** — 缓存地址映射的快表（5、6）。
- **VFS / VMM** — 虚拟文件系统/虚拟机监视器（8、11）。
- **安全状态** — 存在满足全部最大需求的完成顺序（3）。
- **保护域** — 一组对象访问权限（8、12）。
- **并发 / 并行** — 同段时间推进/同一时刻执行（1）。
- **抖动** — 频繁换页压倒有效执行（6）。
- **工作集** — 最近时间窗口访问的不同页集合（6）。
- **共享** — 多个并发活动复用资源（1）。
- **管程** — 封装共享状态并提供互斥过程与条件等待（4）。
- **挂起** — 进程被暂停，可能移至外存（2、3）。
- **缓冲 / 缓存** — 协调速率时序/利用重复访问（5、7）。
- **互斥** — 排他使用同一临界资源（4）。
- **饥饿** — 长期因分配策略等得不到服务（3）。
- **进程 / 线程** — 程序执行实例/进程内执行流（2）。
- **就绪 / 阻塞** — 可运行但待 CPU/还缺事件条件（2）。
- **临界资源 / 临界区** — 排他资源/访问它的代码（4）。
- **内部 / 外部碎片** — 已分配区内余量/分散的空闲区（5）。
- **缺页 / TLB 未命中** — 页不驻留/映射不在快表（5、6）。
- **上下文切换** — 保存恢复执行现场以转换运行者（2、3）。
- **事务 / 检查点** — 受约束操作单元/缩短恢复范围的状态记录（9）。
- **死锁** — 多方相互等待，推进事件只能由等待者引发（3）。
- **同步** — 协调执行活动；狭义强调先后依赖（4）。
- **系统调用** — 应用请求内核服务的受控接口（1）。
- **信号 / 信号量** — 事件通知机制/计数和同步机制（2、4）。
- **虚拟存储器** — 逻辑空间按需映射到有限物理驻留页（6）。
- **页 / 段** — 等长管理单位/按逻辑语义划分的单位（5）。
- **异步** — 执行推进速度与交替时机不确定（1）。
- **原语** — 具有原子执行要求的基本过程（1、2、4）。
- **硬 / 符号链接** — 共享文件对象的名字/保存目标路径的文件（8）。
- **认证 / 授权** — 确认身份/决定可执行的访问（12）。
- **中断 / 异常** — 外设等外部事件/指令执行相关事件（1、7）。
- **驻留集** — 进程当前在内存中的页面集合（6）。
