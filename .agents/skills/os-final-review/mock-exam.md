# 大题自测卷

**建议 90 分钟，100 分。** 本卷为依据你的大题考纲编制的迁移练习，不是老师试卷或原书原题。简答按题意作答；计算写过程，不只交数字。做完再打开[参考答案](mock-answers.md)。

## 一、简答（每题 8 分，共 32 分）

1. 列出操作系统的四个基本特征，并解释并发与共享为什么互为条件。单 CPU 是否能实现并发？
2. 比较高级、中级、低级调度的任务。再举出两种会触发进程调度的事件，说明为什么“发生中断”不一定等于“换到别的进程”。
3. 解释临界资源与临界区，列出四条临界区准则。记录型信号量初值 2、现值 −1 说明什么？P/V 为什么必须原子？
4. 列出 I/O 软件四层；把“打印格式转换、设备权限检查、给控制器寄存器写命令、中断完成通知”分配到对应层。比较中断驱动与 DMA 的 CPU 参与方式。

## 二、计算与综合（共 68 分）

### 5. 进程调度（14 分）

P1、P2、P3 都在时刻 0 到达，初始队列按此顺序，所需 CPU 时间分别为 5、3、1。无 I/O，无切换开销。分别用非抢占 SJF 和 RR（时间片 2）调度，写时间轴、各进程完成时刻、平均周转时间及平均带权周转时间。

### 6. 银行家算法（14 分）

资源分 A、B 两类，`Available=(1,1)`：

| 进程 | Allocation | Max |
|---|---|---|
| P0 | (1,0) | (3,2) |
| P1 | (1,1) | (2,2) |
| P2 | (0,1) | (1,2) |

求 Need，并判断当前安全性，给一个安全序列。随后在**初始状态**中，P0 请求 `(1,0)`，能否立即分配？写出检查、试分配后的数据和理由。

### 7. 分类生产—消费（14 分）

一个生产者将红/蓝两类物品放入容量为 4 的共享缓冲区。一个消费者只取红，另一个只取蓝。所有放入/取出动作互斥，初始为空，各消费者可选取自己的类别，不要求严格队头。定义信号量与初值，给三个进程的循环伪代码，并解释资源 P 为什么要在互斥 P 之前。

### 8. 缺页率（12 分）

初始页框全空，分配 3 个框，访页序列 `1,2,3,2,4,1,2,3`。分别用 FIFO 与 LRU，写逐次命中/缺页和淘汰页，算缺页率。指出哪次命中更新是否改变后续结果。

### 9. 磁盘时间与 EAT（14 分）

机械磁盘转速 6000 r/min，平均寻道 4 ms，读 4000 B，传输率 `20×10⁶ B/s`，控制器延迟 0.1 ms。先求平均访问时间。

再考虑一个页表查询开销可忽略的请求分页模型：正常一次访问 100 ns，**总缺页率** `p=0.001`；每次缺页增加一次上述磁盘读取的额外开销，无写回和其他开销，之后仍需那次 100 ns 的内存访问。求 EAT，给出统一单位后的公式。
