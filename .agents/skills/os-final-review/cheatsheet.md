# 考前速查：按条件选公式

| 题目提示 | 立刻做什么 / 算什么 |
|---|---|
| OS 特征 | 并发、共享、虚拟、异步；并发/共享互为条件 |
| 调度层次 | 高级接纳作业，中级换入换出，低级选就绪者获 CPU |
| 调度计算 | `T=完成−到达`；`W=T/服务`；分别求均值 |
| SJF / SRTF | 先查是否抢占；SRTF 比剩余时间 |
| RR | `运行=min(q,剩余)`，未完成入尾；边界事件按题设 |
| 银行家 | `Need=Max−Allocation`；`Need≤Work`逐维比；完成后 `Work+=Allocation` |
| 新资源请求 | 查 Need、查 Available、试分配、安全检查、提交/回滚 |
| P/V | P：减后 `<0` 阻塞；V：加后 `≤0` 唤醒；资源 P 在互斥 P 前 |
| 临界区 | 空闲让进、忙则等待、有限等待、让权等待（教材第四条非必须） |
| 生产消费 | `empty=N,full=0,mutex=1`；有类别则拆 full |
| 缺页率 | 缺页/本序列访问数；预装不计，空帧装入也算缺页 |
| FIFO / LRU / OPT | 最早装入 / 最久未用 / 未来最晚再用 |
| TLB 未命中 | 先查主存页表，未必缺页 |
| 单级分页，无缺页 | 串行 TLB、忽略更新：`h(λ+t)+(1−h)(λ+2t)` |
| 缺页 EAT | 先列互斥分支；若 p 是总缺页率、F 为额外处理：`EAT=t+pF`（正常路径为 t 时） |
| 条件概率 | `总缺页率=(1−TLB命中率)×未命中下缺页率` |
| 磁盘转速 R r/min | 一圈 `60000/R ms`，平均旋转 `30000/R ms` |
| 磁盘一次访问 | 寻道+平均旋转+传输量/传输率+题给控制器时间 |
| 磁盘调度 | `总距离=Σ|后−前|`；SCAN 的端点/最远请求折返先定 |
| 缓冲稳态 | 单：`max(T,C)+M`；双：`max(T,C+M)`；少量块另画全程 |
| 单位 | `1ms=1000µs=10⁶ns`；`1µs=1000ns` |
