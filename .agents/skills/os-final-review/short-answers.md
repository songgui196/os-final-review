# 四类简答题：背关键词，答清因果

**写法：** 先用一句话定义，再分点写机制，最后补一个区别或例子。下面的答案是按教材重写的答题参考；问什么写什么，不必在“简述特征”里默写调度算法。

## 1. 操作系统的特征

**教材：** §1.3，书 p.15–18 / PDF 36–39；习题 1 第 11、12、27 题，书 p.37–38 / PDF 58–59。

**问：OS 有哪四大特征？它们是什么关系？**

1. **并发：** 多个活动在同一时间段内推进。单核可以通过交替调度实现并发；同一时刻实际同时执行才叫**并行**。
2. **共享：** 系统资源供多个并发进程使用。有的必须**互斥共享**，如用打印机输出；有的可在一段时间内由多个进程**同时共享**，不要求每个底层操作物理上同刻发生。
3. **虚拟：** 用管理机制把物理资源呈现为多个或不同形态的逻辑资源。例如时分复用让进程获得自己的执行流；虚拟存储器把进程可用的地址空间和实际驻留内存分开。
4. **异步：** 进程因资源、I/O、中断、调度等原因走走停停，具体推进速度和交替次序不可预先确定，但同步机制仍可约束必须满足的先后关系。

**关系得分句：** 并发带来对同一批资源的共享需求；有效的共享管理又让多个进程得以安全、有效地并发。因此教材将两者视作互为条件的基本特征。虚拟把资源复用呈现为逻辑资源，异步是并发下进程推进速度不确定的表现。

**变式：** 若问“异步为何不等于结果任意”，答“调度顺序不保证，但可用互斥保证一致性、用同步保证必要的先后”。若题目问 OS 的功能，另写处理机、存储器、设备、文件和接口管理，不用四特征代替。

## 2. 处理机调度

**教材：** §3.1–3.3，书 p.74–89 / PDF 95–110；习题 3 第 1、5–8、10–12、15–16 题，书 p.106 / PDF 127。

**问：三个层次各做什么？为何设中级调度？**

| 层次 | 对象与动作 | 目的或频率 |
|---|---|---|
| 高级（长程、作业调度） | 从外存后备队列选作业，接纳进入内存，创建进程并安排进入就绪队列 | 控制接纳数量、调节多道程序度；频率低 |
| 中级（中程、内存调度） | 使暂不能运行的进程挂起并适时换出；从外存选择已具备条件的进程重新换入 | 缓解内存压力，提高内存利用率和吞吐量 |
| 低级（短程、进程调度） | 从就绪队列选进程/线程，由分派程序交付 CPU | 最基本、最频繁；包括保存当前现场、选择并恢复新进程现场 |

**问：什么时候会进行进程调度？** 当前进程结束、主动让出 CPU 或因等待 I/O/资源阻塞时要另选进程；在抢占式系统中，时间片用完、较高优先级进程到达或唤醒、较短剩余任务就绪等事件也可触发重选。具体是否切换由调度策略决定；并非每次中断或就绪事件都会切换。

**问：抢占与非抢占的区别？** 非抢占通常让已运行进程运行到完成或阻塞（也可主动让出）；抢占允许按**优先级、较短剩余时间或时间片**等原则剥夺 CPU。前者开销较低但响应可能慢；后者便于快速响应、满足实时需要，但切换耗时。

**问：如何选择算法？** 批处理重视吞吐量、周转时间和利用率；分时重视交互响应和公平，常用 RR；实时重视截止时间和可预测性，可用 EDF 或 LLF。`松弛度 = 截止时刻 − 当前时刻 − 剩余执行时间`。多级反馈队列根据用片等运行行为调整进程所在队列，不等于把进程永久分组。

**变式：** FCFS 简单、到达顺序公平，但长任务拖住短任务；SJF 在选择时偏向短作业，能降低许多批处理场景的平均等待，但需要估计服务时间，长作业可能饥饿。RR 的时间片太小增加切换，太大近似 FCFS、交互响应变差。若考“优先级倒置”，先说明低优先级进程持有高优先级进程需要的锁，中优先级进程又占用 CPU；优先级继承可临时提高持锁者优先级。

## 3. 进程同步

**教材：** §4.1、§4.4–4.6，书 p.110–113、116–130 / PDF 131–134、137–151；习题 4 第 1–5、8、10–12 题，书 p.134 / PDF 155。

**问：同步、互斥、临界资源和临界区分别是什么？**

- 狭义**同步**处理合作进程的时序依赖，如先生产再消费；**互斥**处理竞争同一资源时的排他关系，如同一时刻只能一人修改队列。广义的同步机制也包括互斥。二者可以同时存在。
- **临界资源**是一次只允许一方使用的共享资源；**临界区**是进程访问该资源的代码段。不同进程中访问同一资源的临界区需要彼此互斥，不是所有不同资源的临界区都必须串行。
- 解决临界区问题的准则：**空闲让进**（有空则准入）；**忙则等待**（有人用则不能同时进入）；**有限等待**（不会无限被插队）；**让权等待**（不能进入时释放 CPU，教材注明原则上应遵循但非必须）。

**问：记录型信号量 P/V 怎么工作，为什么必须原子？** `P(S)` 先减 1，若结果 `<0`，进入该信号量队列阻塞；`V(S)` 先加 1，若结果 `≤0`，唤醒一名等待者，使其可被调度。负值的绝对值是等待进程数。若测试、改值、入队可被交错执行，可能丢计数、丢唤醒或允许两者同进临界区。例如初值 1，两进程若都先读到 1 再各自写回 0，都会误以为取得了唯一许可。

**问：管程是什么？** 管程封装共享数据及操作，同一时刻只让一个进程/线程在管程内执行；条件变量用于等待/通知某个条件。`wait` 让调用者等待并允许其他调用者进入，条件满足后的通知不等于把条件“累加”起来。若题目区分 Hoare 与 Mesa 管程，按题设交接；唤醒后要重新竞争锁的语义下用循环重查条件。

**常见失分点：** 将互斥写成“保证谁先谁后”；将所有等待写成自旋；把记录型信号量的负值误判为“负的剩余资源”。[生产者—消费者专题](exercises/03-producer-consumer.md)可练初始化、先检查资源后加锁、释放与通知。

## 4. I/O 系统

**教材：** §7.1–7.7，书 p.200–238 / PDF 221–259；习题 7 第 1–12、19 题，书 p.245–246 / PDF 266–267。

**问：I/O 系统有哪些基本功能？** 隐藏设备细节，提供设备无关性，提高 CPU 与 I/O 设备利用率，控制设备，正确分配与共享设备，发现和处理错误。设备无关性指上层使用统一接口/逻辑设备名，不依赖特定物理设备；驱动才负责硬件差异。

**问：I/O 软件有哪四层？** 从上到下答：

| 层次 | 关键职责 | 习题 7 第 2 题的例子 |
|---|---|---|
| 用户层 I/O 软件 | 库函数、面向用户的数据格式处理、假脱机的上层服务 | 把二进制整数转换为可打印的 ASCII 字符 |
| 与设备无关的 I/O 软件 | 统一接口和命名，设备保护、分配/回收，通用缓冲、错误处理 | 检查使用权限；通用缓冲管理 |
| 设备驱动程序 | 将统一请求转换为特定设备命令，配置控制器并启动 I/O | 向设备寄存器写命令 |
| 中断处理程序 | 响应中断，读取与处理完成状态，向上报告或唤醒等待者 | 设备完成后通知等待 I/O 的进程 |

硬件不计入这四层。应用发起请求沿层次向下，完成状态与错误向上报告。设备控制器可用“CPU 接口、设备接口、控制逻辑”回答组成，数据/状态/控制寄存器承担传输、状态报告与命令接收。

**问：轮询、中断驱动、DMA、通道有何异同？**

| 控制方式 | 谁负责搬运/控制 | CPU 的参与 |
|---|---|---|
| 程序轮询 | CPU 查看状态并逐字节/字搬运 | 等待时反复查询，开销大 |
| 中断驱动 I/O | 设备准备好后发中断，CPU 执行传输服务 | 不必忙等，传输数据仍要 CPU 介入 |
| DMA | DMA 控制器按预设地址、方向和长度在设备与内存间成块传输 | CPU 初始化，通常在块完成/异常时处理通知 |
| I/O 通道 | 通道执行通道程序，可组织一系列 I/O 操作 | CPU 提交通道程序和接收结果，不需逐块控制 |

**问：SPOOLing 和缓冲有什么作用？** 假脱机系统用外存输入/输出井、内存输入/输出缓冲区、输入/输出进程和井管理，实现独占设备的逻辑共享。例如进程把打印数据提交到输出井排队，后台进程串行送给打印机，打印机没有被物理上同时使用。缓冲主要缓和生产消费的速率和粒度差异、增加重叠；缓存主要利用重访减少低速访问。若问单缓冲的稳态周期，`T` 和 `C` 可并行，拷贝 `M` 占一个串行段，故 `max(T,C)+M`。
